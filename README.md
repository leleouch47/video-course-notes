# video-course-notes

把网课／速成课视频（尤其 B 站分 P）转成**结构化学科笔记**的工作流。

不是"看完视频写感悟"，而是：抽帧读板书 → 按考纲裁剪 → 每个知识点附一道自测题 → 生成能跳着看的分钟级时间地图。产出的是可以直接拿去复习、也能自我检测的材料。

## 它解决什么问题

- **视频很长，不知道哪段讲什么** → 时间地图把每个分 P 切成「时间段 + 内容」，精度 3 分钟一级，想复习哪节直接跳。
- **看了笔记以为懂了，一做题就空** → 每个知识点后强制附一道自测题，优先用视频里讲过的例题；没有例题就出判断/问答题。问题与选项分行、答案后置，先把问题放最底下，测完再往下划看答案。
- **说"回看原视频"却不知道在哪** → 抽帧时当场落盘 `帧号 → 秒 → mm:ss → 联系表编号` 索引，每个待核项都能定位到具体分 P 和时间。
- **数字抄错** → 所有可复算的结论（ASL、WPL、排序每趟、复杂度）用脚本验一遍，与已有材料冲突时先怀疑自己。

## 快速开始

```bash
# 1. 拿到每个分 P 的 cid、标题、时长
python scripts/bili_pages.py BV1eaCPYSEtH --json pages.json

# 2. 下载指定分 P，每 20 秒抽一帧、缩到 780 宽，9 帧拼一张联系表
python scripts/download_and_frames.py BV1eaCPYSEtH --pages 4-12 --out work \
    --interval 20 --width 780 --per-sheet 9
```

产出：

```
work/
├── p4.mp4                 源视频
├── p4/frames/f_001.jpg …  抽出的帧
├── p4/sheets/sheet_01.jpg 3×3 联系表，每格标了文件名
├── frames_index.csv       帧号 / 秒 / mm:ss / 联系表编号
└── meta.json              每 P 时长、帧数、drift 漂移校验
```

**先看 `meta.json` 的 `drift`**：`|帧数 × interval − 时长|` 应小于一个 interval，偏大说明抽帧不完整，别急着读图。

然后用看图工具逐张读联系表（每张 3×3、9 格全部读完，不要抽查），把板书文字按顺序列成草稿，再按章节骨架组织成笔记。

## 七条硬原则

1. **先抽帧，后转写。** 标题、公式、例题、板书都在画面上；只有画面确实是人像、没有文字时才退回语音转写。
2. **时间戳当场记。** 事后靠印象反推，算出的是不可用区间。
3. **只写画面实际存在的内容。** 读不清的标「待核」并给出定位，不脑补。
4. **按考纲裁剪。** 用户说过不考的内容，视频里讲了也不整理。
5. **数字必须复算。** 例题答案、复杂度这类可独立验算的用脚本算一遍。
6. **中间产物最后清。** 视频、帧、联系表在交付确认后删除。
7. **每个知识点后附一道自测题。** 优先网课例题，否则问答/判断题；题干与选项分行、答案后置、标网课时间戳。

## 笔记格式

每个知识点固定五段：

```markdown
## 知识点 N：标题

**是什么**：一句话定义或核心结论
**关键点**：分条列（公式表 / 代码 / 性质）
**例题**：题干 + 过程 + 答案
**易错点**：视频提醒的坑，或复算发现的坑
**自测**：一道题（问题与选项分行，答案后置）
```

自测题排版示例：

```markdown
**自测**　（网课 P4 08:40）
入栈序列 1,2,3,4,5，哪个不可能是出栈序列？
A. 45132
B. 54321
C. 45321
D. 12345

<details><summary>答案与解析（做完再看）</summary>
答案：A。理由：要输出 4 需先压 1-4 再弹 4；此时栈内 1,2,3，
若接着要 1 必须先弹 3、2，不可能跳过 3 直接到 1。
</details>
```

## 时间地图格式

| 时间 | 内容 |
| --- | --- |
| 00:00–05:20 | 考点表、栈的定义、LIFO、六个基本操作 |
| 05:40–08:20 | 顺序栈结构体、初始化、判空、入栈、出栈 |
| 08:40–11:20 | 出栈序列例题（1–5，判断可能性） |

精度写在表头：`fps=1/20` 时第 i 帧在 `(i−1)×20` 秒；联系表每 9 帧一张时，第 n 张覆盖第 `9(n−1)+1 … 9n` 帧；误差 ±20 秒。**不装作精确到秒。**

## 真实示例

`examples/数据结构-示例笔记.md` 用「数据结构期末速成课」的真实片段演示：栈的顺序存储、哈夫曼树两个知识点，各带网课例题和自测题，以及一段时间地图。

## 依赖

- Python 3.9+（`urllib` 标准库即可取 B 站接口）
- `imageio-ffmpeg`（脚本自带 ffmpeg 路径探测；本机路径也可在脚本里改）
- 看图工具：需要能逐张查看图片（本工作流原使用 WorkBuddy 的 ViewImage）

## 关于 Notion

写入 Notion **不是默认步骤**，只有用户明确说"放进 Notion / 收录到笔记库"时才做。写法见 `references/notion-layout.md`：三栏布局、`<page>标题</page>` 就地建子页、块级公式用独立三行 `$$`、写操作报 internal_error 时等 30–90 秒重试。
