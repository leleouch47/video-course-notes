## 知识点 1：顺序栈

- **是什么**：用一组连续存储单元存放栈元素，附一个 `top` 指示栈顶位置的线性表。只允许在栈顶插入/删除，特性 LIFO。
- **关键点**：
  - 教材（严蔚敏第 3 版）约定：`top` 指向**栈顶元素的下一个位置**，空栈 `top == base`；入栈 `*S.top++ = e`（先存值、后指针 +1），出栈 `e = *--S.top`（先指针 −1、后取值），取栈顶 `*(S.top−1)`。
  - 网课 P4 用的是另一套约定：`top` 初值 = −1、指向栈顶元素本身；入栈 `S.data[++S.top] = x`、出栈 `x = S.data[S.top--]`。
  - **两套都对，但代码写法不同**——考试按老师/教材的约定写，别混。
  - 基本操作：`InitStack`、`StackEmpty`、`Push`、`Pop`、`GetTop`、`DestroyStack`。

- **例题**（网课 P4 08:40）：入栈序列 1,2,3,4,5，判断哪个不可能是出栈序列：A 45132 / B 54321 / C 45321 / D 12345。

  解法：拿一个栈照样模拟。要输出 4，必须先把 1、2、3、4 依次压入再弹 4；此时栈内剩 1,2,3（栈顶 3）。若接着要 5，压 5 再弹 5；栈内仍是 1,2,3。若再要 1，必须先弹出 3、2，所以顺序只能是 3,2,1，不可能跳过 3 直接到 1。

  **答案：A 45132 不可能**；其余三个都能模拟出来。

- **易错点**：入栈/出栈的"指针先动还是取值先动"别反；教材与网课两套约定别混用。

- **自测**（网课 P4 08:40　同一题换个问法）
  入栈序列 1,2,3,4,5，下列哪个**不可能**是出栈序列？
  A. 12345
  B. 45321
  C. 54321
  D. 45132

  <details><summary>答案与解析（做完再看）</summary>

  答案：D。4 出来后栈内 1,2,3（栈顶 3），压 5 再弹 5；接着要 1 就必须先弹 3、2，顺序只能是 3,2,1，不可能跳过 3 直接到 1。
  A 12345：边进边出，每次压入立刻弹出，可行。
  B 45321：4、5 之后依次弹 3、2、1，可行。
  C 54321：全压全弹，可行。
  </details>

## 知识点 2：哈夫曼树

- **是什么**：带权路径长度 WPL 最小的二叉树。结点的带权路径长度 = 根到该结点的路径长度 × 该结点权值；WPL = 所有叶子带权路径长度之和。
- **关键点**：
  - 构造四步：① 每个权值当一棵只有根的树；② 选根权最小的两棵合并（小左大右）；③ 新树根权 = 两子树根权之和，放回森林；④ 重复到只剩一棵。
  - 算 WPL 两法互校：逐叶子 `w × 深度` 求和；或把所有合并产生的新根权相加（本题 `2+4+8+14=28`）。
  - 哈夫曼树不唯一（左右可换），但 WPL 唯一。
- **例题**（网课 P7 26:40，练习 1 原题）：权值 a:4, b:6, c:2, d:1, e:1，构造哈夫曼树（左 0 右 1），写编码、求 WPL。

  四轮合并：`1+1=2`、`2+2=4`、`4+4=8`、`6+8=14`。
  编码（按左 0 右 1）：`b=0, a=10, c=110, d=1110, e=1111`。
  WPL = `6×1+4×2+2×3+1×4+1×4 = 28`；自检 `2+4+8+14 = 28`。

- **易错点**：第 3 轮新产生的结点权值与 a 打平（都是 4），也是候选，别只用原始权值；层数直接当码长时记得根算第 0 层。

- **自测**（网课 P7 26:40）
  权值 2, 4, 5, 7, 9, 15, 23 构造哈夫曼树，WPL 是多少？
  A. 156
  B. 163
  C. 170
  D. 178

  <details><summary>答案与解析（做完再看）</summary>

  答案：B，WPL = 163。
  排序 2,4,5,7,9,15,23 → 合并顺序：2+4=6、5+6=11、7+9=16、11+15=26、16+23=39、26+39=65。
  把六个新根权相加：6+11+16+26+39+65 = 163。两种算法一致。
  </details>
